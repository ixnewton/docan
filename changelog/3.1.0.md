# 3.1.0

## New Features
- Added OpenRouter as a provider: browse all vendors and models via a three-level selector (provider → vendor → model) with vendor brand icons.
- Model menus list only currently available models, fetched live from each provider's API; stale saved models self-heal automatically.
- Each provider remembers its last-used model across restarts and provider switches.

## Improvements
- Conversations are stored in a dedicated file; existing history migrates automatically on first launch (much faster settings saves).
- Rate-limit fallback retries from the provider's live model list (capped) instead of a hardcoded list.
- Refreshed built-in Gemini and Claude model lists to current APIs.
- API errors surface the provider's actual error message.
- Fixed sidebar list tiles' hover/press ripple rendering.
