# 3.0.0

## New Features

### AI Providers
- Added DeepSeek AI support with `deepseek-chat` and `deepseek-reasoner` models.
- Added LM Studio support with OpenAI-compatible API.
- Dynamic model fetching from API (no hardcoded model lists).

### Image Creator
- Added dedicated Image Creator screen for generating images with AI.
- Supports Gemini and OpenAI DALL-E providers.
- Gallery view to browse generated images.
- Multiple image size options.
- Save images to downloads folder.
- Copy prompt to clipboard.

### Playbooks
- Added Playbooks: User-created YAML integrations for extending Docan.
- Create custom API integrations with a simple YAML SDK.
- Trigger-based activation using regex patterns.
- Multiple step types: HTTP requests, webhooks, transforms, conditions, loops.
- Template syntax for dynamic variable substitution.
- Configuration fields for API keys and settings (with secret support).
- Import/export playbooks as YAML files.
- Platform-specific playbook support.
- Built-in example playbooks for OpenLyst APIs.
- Full documentation at `docs/playbooks.md`.
- Use `/playbook <name>` command to explicitly use a specific playbook.
- Auto-detection: Playbooks automatically activate based on trigger patterns.
- Added help button to open online documentation from Playbooks screen.
- New Playbook button opens YAML editor with template.

### Playbook Engine Upgrade
- Multi-step logic with state memory across execution.
- Configurable `retries` and `retryDelayMs` per step.
- `onFailure` option supports `throw`, `continue`, or `returnError`.
- Secure storage for secret config values (API keys).
- Input validation with `validateParameters()`.
- Progress streaming via `executeStream()` for real-time updates.
- Dry run capability with `dryRun()`.
- Fuzzy matching for improved trigger confidence.
- Configurable timeout support for HTTP requests.

### Attachments & Drag-and-Drop
- Added support for attachments in chat.
- Show images that the user sent in chats.
- Drag and drop files directly onto the app.
- Visual overlay indicator when dragging files.
- Supported formats: txt, pdf, doc, docx, md, json, csv, png, jpg, jpeg, gif, webp.

### Chat Improvements
- Added support for custom system prompts.
- Links in chat messages are now clickable and open in external browser.
- Restored LaTeX math rendering support in chat messages.
- Auto-scroll to bottom when sending messages and during AI streaming.
- Smart auto-scroll pauses if user scrolls up to read previous content.

## UI/UX Improvements
- Use dropdowns instead of popouts.
- Scrollable model selector for phones.
- Bigger and more spacious settings dialog on desktop.
- Disable hover tinting on settings dialog.
- Attachment button opens file picker directly on desktop.
- Hide camera option on non-mobile platforms.
- Darken AI chat bubbles for better contrast.
- Move less rounded corner to top of chat bubbles.
- Close button added to desktop Playbooks screen.
- Improved playbook configuration UI with field types and password visibility toggle.
- Responsive design for desktop and mobile.

## Bug Fixes
- Fixed saving API keys on Linux.
- Fixed new line in text box when sending a message.
- Fixed provider selector overflow on smaller screens.
- Fixed playbook `returnData` step not returning data.
- Improved API error handling for quota limits, rate limits, and authentication errors.

## Other Changes
- Removed agents.
- Removed old Gemini model (2.0-flash).
- Use temperature settings for Claude.
- Refactored playbook integration in chat service with cleaner system prompts.
