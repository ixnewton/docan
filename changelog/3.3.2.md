# 3.3.2

## Features
- **AI-assisted playbook creation** — Describe what a playbook should do in plain language and the configured AI provider generates a complete, valid playbook for review before saving.
- **Workflow flowchart** — Playbook detail views now show the trigger and step workflow as a visual flowchart (type-coded step nodes, condition branches and loop bodies indented).
- **Step editing from the flowchart** — Tap any step node to edit its YAML block in place; changes are validated and saved through the normal import path.
- **Playbook YAML source editor** — The full YAML editor is now reachable when creating a new playbook (previously only for editing existing ones).

## Improvements
- Removed the liquid-glass widget set in favour of standard Material components (buttons, fields, containers, nav bars) — the UI is now entirely standard Material.
- The model dropdown grows to fit model names and pricing rates without ellipsis, clamped at the panel's right margin.
- The floating chat title pill is white at 95% opacity with the title shown in double quotes.
