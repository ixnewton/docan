# 3.3.3

## Features
- **Image history** — Saved images are recorded with the prompt that created them, ordered by date. The Image Creator sidebar shows unsaved session images on top, then the saved history grouped by day: the newest day's thumbnails expanded by default, previous days as labels. Clicking a day label shows only that day's thumbnails; clicking any thumbnail opens it in the main display. Images deleted from the folder disappear from the list.
- **Configurable save folder** — Settings → Image Generation sets the image save folder (default `~/Documents/Docan`); a changed path becomes the default.
- **Unsaved-image exit prompt** — Leaving the Image Creator with unsaved images asks "Save/download images or Exit?": Save keeps you in the creator, Exit leaves without saving.
- **OpenRouter image generation** — The Image Creator now offers OpenRouter's image-capable models via the same three-level provider → vendor → model selector as text chat, sourced from the `/images/models` endpoint, with per-model pricing rates, image spend tracking, and the credit balance chip. Generation uses the dedicated `/images` endpoint with a chat-completions fallback.

## Improvements
- The model selector was generalized to provider descriptors so the chat and image screens share one component.
- The build is now warning-free: the remaining analyzer warnings were cleared and the third-party C++ deprecation warnings from flutter_secure_storage_linux are suppressed in the Linux build.
