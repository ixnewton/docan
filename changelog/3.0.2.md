# 3.0.2

## New Features
- Remember the last-used model per provider; selections persist across restarts and provider switches.
- Prefetch live model lists at startup for configured providers, with caching for instant model pickers.

## Improvements
- Replaced custom Liquid Glass components with standard Material Design widgets.
- API errors now surface the provider's actual error message (OpenAI and Gemini streaming), e.g. quota vs rate limit.
- Linux middle-click paste via PRIMARY selection with debounced text selection handling.

## Bug Fixes
- Fixed DOCX text extraction using unzip with improved UTF-8 encoding fallbacks.
