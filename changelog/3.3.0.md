# 3.3.0

## Features
- **Streaming display** — Replies render as they arrive: text feeds in line-by-line on a buffered cadence, and completed tables insert as stable structures instead of waiting for the whole response. Completed blocks are memoized so long responses stay smooth.
- **Prompt history** — Up/Down arrows recall previous prompts, terminal-style. The cursor position decides: arrows navigate history only on the first/last line of the input, so multi-line editing still works. Past the newest entry your in-progress draft is restored.
- **Per-chat provider memory** — Each chat records the provider and model combination actually used (including rate-limit fallback models) and restores it when the chat is continued or reopened.
- **Smart startup selection** — After the startup availability tests, if the saved provider is unavailable (local server stopped, key removed), the menu selects the most recently used provider that is available. The saved preference is never overwritten.
- **Usage and cost tracking** — Token usage is captured from the provider streams and accumulated per chat and per provider/model. The toolbar shows the current chat's cumulative tokens and cost; OpenRouter model menus show live per-model pricing rates, and the credit balance chip shows remaining credits.
- **Floating chat title** — The chat title moved from the toolbar into a floating pill below it, freeing the toolbar for the selectors and usage displays.

## Fixes
- The reply panel no longer flashes as an empty grey block before content arrives: it is hidden until the first line of content is inserted, and text selection is enabled only once the response completes.
