# 3.3.4

## Features
- **Delete displayed image** — A bin action in the Image Creator toolbar deletes the image currently displayed: a saved image loses both its file and its history record; a session image is removed from the list.
- **Image prompt history** — Up/Down arrows recall previous image prompts (from the saved history and this session), terminal-style, for editing and regenerating.
- **App-close guard** — Closing the application while the Image Creator has unsaved images shows the exit alert: "Select and save" cancels the close, "Exit" closes the application.

## Improvements
- The unsaved-images exit alert now appears only when unsaved session images exist, with the clearer message "Select and save images or Exit"; "Select and save" simply closes the alert so you can select and save images yourself.
- The image delete action sits at the end of the toolbar icons, after copy.
